# ChannelSeal

> ChannelSeal scores, monitors and protects the interfaces AI agents reach — APIs, MCP servers and other agents — with an Interface Scorecard per interface, sensitive-data-flow identification from schemas and metadata (no payload inspection), and inline runtime policy enforcement inside the customer's environment. Invite-only founding-customer stage (2026). This file was generated by API Evangelist from the provider's public surface on 2026-09-20; the provider publishes no llms.txt of its own (docs.channelseal.com/llms.txt and www.channelseal.com/llms.txt both 404).

Authentication: OAuth 2.0 client credentials → Bearer token (1 h) from https://dev-channelseal.us.auth0.com/oauth/token with audience https://api.channelseal.com; scopes read, write, delete, admin. Base URL https://{api|uat}.channelseal.com/{platform|catalog}; the production host did not resolve in DNS on 2026-09-20. Errors are RFC 9457 application/problem+json. Rate limits: Free 100/h, Pro 1,000/h (X-RateLimit-* headers, Retry-After on 429). Pagination: page/size/sort → content[] + page{size,number,totalElements,totalPages}. No idempotency key, no dry-run, no reversal for deletes (including eleven delete-all operations).
